# CO2 Dashboard
Diese Webanwendung wurde im Rahmen einer Fallstudie entwickelt und zeigt fiktive CO2-Emissionsdaten von Ländern & Unternehmen. 

## Features 
- Layout mit Header, Navigation, Content-Bereich und Footer
- Vergleichstabelle, um zwei Länder bzw. Unternehmen miteinander zu vergleichen
- Responsives Design für Desktop, Tablet und Smartphone
- Tabelle miti soriter- und filterbaren Emissionsdaten
- Eingabefeld ist gegen Code-Injektionen geschützt
- Webanwendung verfügt über eine Datenschutz- und Impresesumsseite

## Projektstruktur 
- index.html -> Startseite
- imprint.html -> Impresum
- privacy.html -> Datenschutz
- countries.json -> Datendatei
- assets/css/ -> Stylesheet
- assets/js/ -> Skripte
- assets/img/ -> Logo

## Nutzung 
index.html im Browser öffnen
